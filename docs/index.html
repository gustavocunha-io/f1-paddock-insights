OS 3 PILARES DE WEB SERVICES

O sistema combina três abordagens fundamentais para obter, transformar e gerar inteligência de dados esportivos.

📡 API REST PÚBLICA

OpenF1 API

GET api.openf1.org/v1/drivers

Consumo oficial de endpoints de telemetria e cadastros da F1. O backend realiza buscas inteligentes tolerantes a falhas por sobrenome, primeiro nome ou nome completo.

  • Fotografia oficial do piloto (headshot)
  • Número oficial do carro no grid (#12, #1, #44)
  • Código do país de origem (ITA, NED, GBR)
  • Cor hexadecimal da escuderia (ex: Mercedes #00A19C)
🌐 WEB SCRAPING

Grande Prêmio

HTML Parsing via BeautifulSoup4

Raspagem em tempo real desenvolvida com BeautifulSoup e Expressões Regulares (`re`). Extrai tanto notícias contextuais quanto a tabela geral de classificação do mundial.

  • Filtro dinâmico de notícias por piloto
  • Raspagem de títulos e corpos de matérias completas
  • Tabela oficial com mais de 20 pilotos e pontos
  • Mecanismo de delay (3s) para proteção contra DDOS
🧠 LLM WEB SERVICE

Google Gemini AI

google-genai (gemini-3.5-flash-lite)

Geração de comunicação de rádio realista do Pit Wall. A inteligência sintetiza os dados do OpenF1, a tabela de pontuação e as últimas notícias em um prompt contextual.

  • 🔧 Engenheiro Sério: foco em telemetria e pneus
  • 🎙️ Narrador Emocionado: alta adrenalina e épico
  • 🏁 Comentarista Corneta: humor ácido e zoeira de paddock
  • 🔄 Rodízio Automático de Chaves (Round-Robin & Fallback)
  • 🔒 Chaves inseridas via UI (Zero dependência de .env)
  • Formatação limpa renderizada via Python-Markdown

💻 Guia do Desenvolvedor

COMO EXECUTAR O PROJETO LOCALMENTE

Siga as instruções abaixo para rodar o backend Flask e todas as integrações de Web Services no seu computador.

PASSO 01

Clonar o Repositório Git

Abra o terminal no diretório desejado e faça o clone do projeto oficial:

git clone https://github.com/gustavocunha-io/f1-paddock-insights.git
cd f1-paddock-insights
PASSO 02

Criar o Ambiente Virtual & Instalar Dependências

Você pode utilizar o gerenciador Conda ou o padrão Python Venv com Pip:

# Opção A: Utilizando Python Venv padrão
python -m venv venv
# No Windows:
.\venv\Scripts\activate
# No Linux/Mac:
source venv/bin/activate

pip install -r requirements.txt

# Opção B: Utilizando Conda
conda env create -f environment.yml
conda activate web_services
PASSO 03

Chave(s) de API do Google Gemini (Direto no Input)

Não é necessário criar arquivo .env! Para publicação segura no GitHub sem expor credenciais, insira sua chave (ou múltiplas chaves separadas por vírgula para rodízio automático) diretamente no campo do formulário da aplicação. A chave fica salva no navegador (localStorage): 

AIzaSyChave1Exemplo..., AIzaSyChave2Exemplo...
PASSO 04

Iniciar o Servidor Flask

Execute o arquivo principal para inicializar a aplicação na porta padrão 5000:

python paddock.py

✓ Pronto! Acesse pelo seu navegador em: http://localhost:5000
