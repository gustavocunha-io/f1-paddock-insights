# Vídeo de Demonstração (Demonstration Video)

Este diretório contém os recursos de vídeo da página do GitHub Pages do projeto **F1 Paddock Insights**.

## Como adicionar ou substituir seu vídeo de demonstração:

1. Grave a demonstração do sistema (por exemplo, usando OBS Studio, Loom, gravação nativa do Windows `Win + Alt + R` ou gravação de tela do celular).
2. Salve ou exporte o vídeo no formato **MP4** (`demo.mp4`).
3. Coloque o arquivo `demo.mp4` diretamente nesta pasta (`docs/assets/videos/demo.mp4`).
4. O player HTML5 na página principal (`docs/index.html`) já está configurado para reproduzir este arquivo automaticamente, com poster de prévia, controles responsivos e navegação por capítulos.
5. Caso o vídeo seja hospedado no YouTube, Vimeo ou Loom, você também pode colar o link do `iframe` diretamente no container de vídeo em `docs/index.html`.
